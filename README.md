# EX No.5.2.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:24-11-2026

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1.Launch Fusion 360 and open a new design.

2.Choose the Create Sketch option.

3.Select a suitable plane for drawing.

4.Draw the required design using sketch tools.

5.Finish the sketch.

<img width="256" height="172" alt="Screenshot 2026-11-15 124609" src="https://github.com/user-attachments/assets/52938e7b-8dec-46dd-a7cf-1e814510d96b" />

6.Apply the Extrude command to create a 3D model.

<img width="452" height="560" alt="Screenshot 2026-11-15 133419" src="https://github.com/user-attachments/assets/2142547e-5fff-48d2-b87c-e911ce36b592" />

7.Open the Drawing Mode.

<img width="336" height="412" alt="Screenshot 2026-11-15 124628" src="https://github.com/user-attachments/assets/a8e7f529-06e1-44e0-842b-637a6b759f2a" />

8.Insert the Base View of the model.

9.Create additional views using projected View.

10.Complete the orthographic drawing.

## RESULT:
Thus, the given 3D model is converted into orthographic view.
